# Terraform AWS Production Platform

Infrastructure as Code project demonstrating production-oriented AWS infrastructure provisioning with Terraform.

## Objectives

- Build reusable Terraform modules
- Provision AWS infrastructure using Infrastructure as Code
- Separate environments
- Implement remote Terraform state
- Automate Terraform validation and planning with GitHub Actions
- Integrate infrastructure security scanning
- Implement infrastructure testing
- Simulate infrastructure failures and recovery scenarios

## Architecture

The platform will progressively include:

- AWS VPC
- Public and private subnets
- Internet Gateway
- NAT Gateway
- Security Groups
- IAM
- Compute resources
- AWS Secrets Manager / Parameter Store
- CloudWatch
- Remote Terraform state
- CI/CD with GitHub Actions
